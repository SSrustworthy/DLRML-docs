# Nemo's Submarine Voyage Queue [INC]

**Land(s)**: Tomorrowland

**Loop Total Length**: 00:57:46

This loop plays in the queue for the Nemo’s Submarine Voyage attraction. The loop was confirmed by wedroy1923 to be the same area music as “The Seas with Nemo and Friends”; see Magic Music, [https://community.magicmusic.net/threads/dlr-notes-2-15-09.4046/post-29265.](https://community.magicmusic.net/threads/dlr-notes-2-15-09.4046/post-29265.)  Plays moreso in the loading area than the queue. These are not needledrop tracks and were reorchestrated from the Finding Nemo soundtrack. No track listing has been compiled as a result. See MouseBits, Re:[https://mousebits.com/smf/index.php?topic=10461.msg96387#msg96387](https://mousebits.com/smf/index.php?topic=10461.msg96387#msg96387)
