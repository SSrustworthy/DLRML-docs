# [2002-2003] Grim Grinning Ghosts

**Location**: New Orleans Square

**Loop Total Length**: Unknown

This loop played in the Disney Gallery in New Orleans Square. It was used as part of the Grim, Grinning Ghosts exhibit from 10/2002 to 20/2003. A few tracks were identified by RocketRodsXPR using YouTube videos from the time period. See MouseBits, [https://forums.mousebits.com/threads/the-disney-gallery-music-2-0.7840/post-73222](https://forums.mousebits.com/threads/the-disney-gallery-music-2-0.7840/post-73222)  (2013).
