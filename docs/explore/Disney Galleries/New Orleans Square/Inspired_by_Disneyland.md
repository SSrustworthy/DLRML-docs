# [2007] Inspired by Disneyland [INC]

**Location**: New Orleans Square

**Loop Total Length**: Unknown

This loop played in the Disney Gallery in New Orleans Square. The loop was the BGM for the final exhibit of the Disney Gallery, “Inspired by Disneyland” which was featured in 2007. No tracklist exists for this loop, although RocketRodsXPR has postulated that the loop is the same as “A Magical Canvas.” See MouseBits, [https://forums.mousebits.com/threads/the-disney-gallery-music-2-0.7840/post-73222](https://forums.mousebits.com/threads/the-disney-gallery-music-2-0.7840/post-73222)  (2013).
